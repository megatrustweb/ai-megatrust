# دليل المسؤول — الصلاحيات والتفعيل والمفاتيح (Mega AI)

## ١) مستويات الوصول (Tiers)
| الدور | من؟ | ماذا يرى ويستخدم | الرصيد |
|---|---|---|---|
| ⏳ **USER** (افتراضي) | كل من يسجّل جديدًا | رسالة "حسابك قيد التفعيل" فقط — لا نماذج ولا أدوات | رصيد ترحيبي محجوز (1,000,000 = 1$) |
| 💬 **CHAT_MEDIA** | موظفو الدردشة والمحتوى | Mega Chat (Groq) · Gemini Flash · 🎙️ استوديو الصوت العربي · 🎬 استوديو الصور والفيديو | 300,000/يوم (يتجدد يوميًا) |
| 💻 **CODER** | المبرمجون | ما سبق + Claude + Agents + تشغيل الكود + GitHub + إضافة أدوات MCP | 3,000,000/يوم |
| ⭐ **POWER** | صلاحيات كاملة | كل شيء | 10,000,000/يوم |
| 🛡️ **ADMIN** | مدير المنصة | كل شيء + لوحة الإدارة | — |

- **النماذج المجانية** (Groq / Gemini Flash / نماذج OpenRouter المجانية) سعرها **صفر** — لا تستهلك الرصيد أبدًا.
- **Claude** يُخصم من الرصيد بسعره الحقيقي. (1,000,000 رصيد = 1 دولار)
- الأرقام قابلة للتعديل من: لوحة الإدارة → **Configuration** → اختر الدور → **Balance**.

## ٢) تفعيل موظف جديد
1. الموظف يسجّل بنفسه من صفحة الدخول **بأي بريد** → يدخل تلقائيًا في **USER** (قيد التفعيل).
2. افتح لوحة الإدارة → **Users** → ابحث عنه.
3. انقله من **USER** إلى الدور المناسب (CHAT_MEDIA / CODER / POWER) → يُفعَّل **فورًا**.
4. الرصيد اليومي للدور يبدأ تلقائيًا خلال 24 ساعة (وحتى ذلك الحين يستخدم رصيده الترحيبي).

> إيقاف موظف: أعده إلى **USER** فيرجع لحالة "قيد التفعيل" فورًا.

## ٣) تعيين مسؤولين من فريقك (بدون صلاحية مدير كامل)
من لوحة الإدارة → **Grants** → امنح المستخدم (أو مجموعة/دور) صلاحية محددة:
| المهمة | الصلاحية (Capability) |
|---|---|
| مسؤول تفعيل الحسابات | `manage:users` (+ `read:roles`) |
| مراقب الاستخدام | `read:usage` |
| مسؤول أدوات MCP | `manage:mcpservers` |
| مدير كامل | الدور **ADMIN** |

## ٤) إضافة مفاتيح النماذج (بدون ملف .env)
لوحة الإدارة → **Configuration** → **Endpoints** → **Custom** → اختر المزوّد → الصق المفتاح في **API Key** → حفظ.
المفاتيح تُخزَّن **مشفّرة** وتظهر مخفية بعد الحفظ.

| المزوّد | من أين المفتاح | ملاحظة |
|---|---|---|
| **Groq** (مجاني، سريع) | console.groq.com/keys | لا يُدرِّب على بياناتك — الأنسب للدردشة اليومية |
| **Gemini** (مجاني) | aistudio.google.com/apikey | ⚠️ الطبقة المجانية قد تستخدم البيانات لتحسين خدمات Google — لا تُدخل بيانات حساسة |
| **OpenRouter** | openrouter.ai/keys | نماذج مجانية + مدفوعة بمفتاح واحد |
| **Claude** (مدفوع) | console.anthropic.com | للبرمجة والمهام القوية |
| **Tavily** (بحث الويب الأصلي) | tavily.com (1000 طلب/شهر مجانًا) | Configuration → **Web Search** |
| **fal.ai** (صور وفيديو) | fal.ai/dashboard/keys | Configuration → **MCP Servers** → fal-ai → Headers. ⚠️ **ضع حد إنفاق في لوحة fal.ai** — تكلفة الفيديو لا تُخصم من رصيد المنصة |

## ٥) الصوت العربي باللهجات
- **قراءة الرسائل صوتيًا**: زر 🔊 أسفل أي رد. اختيار الصوت من: الإعدادات → **Speech** (مصري/سعودي/إماراتي/كويتي/قطري/بحريني/عماني…).
- **تعليق صوتي قابل للتحميل (MP3)**: من مواصفة **🎙️ استوديو الصوت العربي** — اكتب الفكرة واللهجة.
- للحصول على نطق عامّي طبيعي: يجب أن **يُكتب النص باللهجة نفسها** (المساعد يفعل ذلك تلقائيًا في استوديو الصوت).
- الملفات الصوتية تُحذف تلقائيًا بعد 7 أيام.

## ٦) الأمان
- أي حساب جديد **لا يستطيع استخدام شيء** حتى تفعّله — مفروض من الخادم (جُرِّب: محاولات تجاوز البوابة تُرفض بـ `Model spec mismatch`).
- الطلبات غير القادمة من متصفح، ومحاولات الإساءة، تؤدي إلى **حظر مؤقت تلقائي** (ساعتان).
- لوحة الإدارة غير مكشوفة للإنترنت — تُفتح عبر نفق SSH فقط.
- فعّل **التحقق بخطوتين (2FA)** لحسابك: الإعدادات → Account.
